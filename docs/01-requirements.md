# NeatDesk — 需求文档

## 项目概述
Windows 桌面整理工具，自动按文件类型整理桌面文件，让桌面更整洁有序。

## 技术栈
| 层面 | 选择 |
|------|------|
| 后端 | Rust + Tauri 2.0 |
| 前端 | Vue 3 + Vite |
| 图标 | Lucide |
| 数据库 | SQLite (rusqlite) |
| 定时器 | tokio |

## 功能需求

### 核心功能
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 按文件类型整理 | 扫描桌面文件，按扩展名归类到对应分类文件夹 | P0 |
| 自定义分类规则 | 用户可新增/编辑/删除分类，配置扩展名规则 | P0 |
| 一键手动整理 | 点击按钮立即执行整理 | P0 |
| 定时自动整理 | 完全自定义的时间间隔自动整理 | P0 |
| 系统后台运行 | 关闭窗口后驻留系统托盘，定时任务持续 | P0 |
| 撤销功能 | 每次整理记录操作日志，支持一键回退 | P0 |
| 自动忽略系统图标 | 跳过"此电脑""回收站"等系统桌面项 | P0 |

### 辅助功能
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 开机自启 | 可选是否开机启动 | P1 |
| 文件重名处理 | 同名文件自动加时间戳后缀 | P0 |
| 排除列表 | 用户指定文件/文件夹不参与整理 | P1 |
| 整理统计 | 展示整理历史（时间、文件数量、分类概况） | P1 |
| 托盘菜单 | 右键托盘快速操作 | P0 |
| 深色/浅色主题 | 跟随系统或手动切换 | P2 |

## 预设分类

| 分类 | 扩展名 |
|------|--------|
| 图片 | .jpg .jpeg .png .gif .bmp .webp .svg .ico .tiff |
| 文档 | .doc .docx .xls .xlsx .ppt .pptx .pdf .txt .md .csv |
| 视频 | .mp4 .avi .mkv .mov .wmv .flv .webm |
| 音乐 | .mp3 .wav .flac .aac .ogg .wma |
| 压缩包 | .zip .rar .7z .tar .gz .bz2 |
| 可执行文件 | .exe .msi .bat .cmd .ps1 |
| 其他 | 未匹配到上述分类的所有文件 |
