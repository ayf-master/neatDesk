## 遇到的问题 & 解决
1. Rust 未安装 → 使用 rustup 安装（版本 1.96.0）
2. mingw 链接器 ld 返回 116 → 添加 MSYS2 UCRT64 到 PATH 解决
3. ICO 图标 PNG CRC 错误 → 生成标准有效 PNG 数据重新创建
4. Vite 8 需要 esbuild 单独安装 → npm install esbuild --save-dev
5. esbuild 不支持 safari14 target → 改为 es2021 + chrome100
6. Rust 所有权和 trait 错误 → 添加 clone() 和 Deserialize derive
