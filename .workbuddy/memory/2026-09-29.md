# 2026-09-29 代码审查与修复

审查 NeatDesk 全量源码（Rust 后端 + Vue 前端），修复 3 个实问题：

1. **配置解析失败会静默清空用户设置（数据丢失）** — `src-tauri/src/config.rs`
   - 旧 `ensure_config`/`load_config` 用 `serde_json::from_str(...).unwrap_or_default()`，config.json 一旦损坏/缺字段（如升级后 schema 变化）整份配置重置为默认并覆盖写回。
   - 修复：新增 `read_config`（解析失败先备份为 `config.json.corrupt-<时间戳>`，再以 `AppConfig::default()` 为基底做 deep-merge 叠加已保存字段）+ `deep_merge` + `backup_corrupt`。缺字段不再整体丢失。

2. **"每 N 小时"定时一天只跑一次** — `src-tauri/src/scheduler.rs`
   - 旧 interval 分支被 `already_triggered_today` 拦截，触发一次后置 true 整天不再触发，与 UI"每 N 小时"语义矛盾。
   - 修复：interval 分支去掉该拦截，只按"距上次整理 >= interval_hours"判定；daily/weekly 仍保留该拦截（防±5min 窗口重复触发）。

3. **`scanner.rs` 的 `is_hidden` 字段永远 false（死字段）** — 改为 `is_hidden: is_windows_hidden(&metadata)`。

## 环境备注
- 本沙箱无法编译 Windows 版 Rust：缺 MinGW binutils（windres/dlltool），`rust-mingw` 新版不再捆绑；`curl`/HTTPS 出网被拦截导致装不了 llvm-tools。需用户在本地跑 `npm run tauri build` 验证。
- 已知未改项（避免行为变更）：`Settings.organize_target_path` 字段后端未使用（整理只用 `Category.target_path`），UI 也未暴露，属冗余字段，仅记录不改动。
