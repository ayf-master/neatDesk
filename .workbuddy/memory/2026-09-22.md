# 2026-09-22 工作日志

## 打包发布（白屏修复后）

用户确认修复版可用，正式打包 MSI 安装包。

**产物**：
- `src-tauri/target/release/bundle/msi/NeatDesk_0.1.0_x64_zh-CN.msi`（~4.9MB，WiX 生成，zh-CN）
- 便携版：`portable/NeatDesk.exe`（已用本次构建刷新）
- 打包版 exe 实测渲染正常（生产模式，确认 custom-protocol 生效）。

**打包命令**：`./node_modules/.bin/tauri build`（即 `npm run tauri build`）。

**打包环境坑（重要）**：
- 前置 `rm -rf dist` 会被工作区「安全删除」包装拦截：`rm` 被改写成"移入回收站"，对 `dist` 目录报 `file in use` → 失败并中断 `&&` 链。
- 现象：`dist` 里的**文件会被删掉，但目录本身删不掉**（`mv dist` 也报 `Device or resource busy`）。
- 绕过：**只要 `dist` 是空的即可**（vite 的 emptyDir 对空目录不再调 `fs.rmSync`），无需删目录本身。所以让 dist 空着直接 build 就能过。
- 打包时 tauri 会 `Downloading https://go.microsoft.com/fwlink/p/?LinkId=2124703`（首次/缓存缺失时拉 WiX）。
- 提示（非致命）：`identifier` 以 `.app` 结尾（`com.neatdesk.app`）会警告与 macOS bundle 扩展名冲突；Windows 无碍，跨平台前可改成 `com.neatdesk.desktop` 之类。

**结论**：白屏两大根因（缺 `custom-protocol` feature / WebView2 GPU 进程崩溃）已从上一日修复；本次仅打包，无代码改动。
